# Knowledge Folder

This MVP uses a simple curated knowledge folder instead of a heavy custom RAG pipeline.

Place short, reliable legal guidance files here in `.txt` or `.md` format. Keep them:

- narrow in scope
- easy to review
- based on official or otherwise reliable public material
- written with headings and plain text so the lightweight retrieval layer can use them

Suggested starter files:

- `constitution_basics.txt`
- `cyber_fraud_basics.txt`
- `consumer_complaint_basics.txt`
- `property_tenancy_basics.txt`
- `criminal_fir_basics.txt`
