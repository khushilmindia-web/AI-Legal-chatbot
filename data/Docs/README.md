# Statute Corpus

Place real central statute and constitutional text files here for ingestion.

Recommended file format:
- Plain `.txt`
- One Act / Constitution part per file where possible
- Prefer article/section/rule headings in this style:
  - `Article 21 - Protection of life and personal liberty`
  - `Section 420 - Cheating and dishonestly inducing delivery of property`
  - `Rule 3 - Procedure`

Recommended sources:
- Constitution of India
- Central Acts relevant to cyber, criminal, family, property, labour, and consumer matters
- Rules and notifications where legally significant

Recommended filenames:
- `Constitution_of_India.txt`
- `Information_Technology_Act_2000.txt`
- `Consumer_Protection_Act_2019.txt`
- `Transfer_of_Property_Act_1882.txt`

After adding files, run the ingestion pipeline.
