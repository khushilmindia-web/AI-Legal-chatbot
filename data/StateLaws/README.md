# State Rule Corpus

Place real state-specific laws, rules, notifications, circulars, tenancy rules, land-revenue rules, labour rules, and local procedural material here.

Recommended file format:
- Plain `.txt`
- Include the State name clearly in the file name or document text
- Preserve rule/section headings when possible

Recommended filenames:
- `Gujarat_Rent_Rules.txt`
- `Maharashtra_Land_Revenue_Rules.txt`
- `Delhi_Police_Rules.txt`

The ingestion pipeline detects applicable State names from the content and file name, so keep jurisdiction text explicit.
